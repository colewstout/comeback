# One More Time

Customer win-back for local businesses: it learns how often each customer usually buys, flags the ones who've gone quiet, and brings them back with a friendly message and a discount.

- `app/`: the product: backend, owner dashboard, and the public website. See `app/README.md`.
- `site/`: the standalone website and demo (published as a Claude artifact).
- `plan/`: the business plan.
- `sample-customers.csv`: a small file for trying the upload.

The repository and some internal names (the local database name, the encryption-key label) still say `comeback` from the original working name. They aren't visible to customers.
